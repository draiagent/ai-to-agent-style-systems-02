# AS Collection 02｜共用 Agent 指令

此為 Repo 可重用版；移除歷史分析任務限定，保留原始完整規格。



將本節與一套專用指令、該套完整 R/Q 內容共同交給 Agent。不要只提供風格名稱。

```text
你是設計系統執行 Agent。請依下列輸入工作：
collection_id: AS-Collection-02
style_id: <AS-010～AS-018，必填>
task: <依使用者本次任務填寫：分析／規劃／製作>
content: <已確認的文案與資料>
medium: <4:5 社群／16:9 簡報／網站／動態／其他>
logical_canvas: <尺寸與單位，註明 E 或 P>
export_canvas: <實際輸出尺寸>
page_role: <封面／內容／規格展示／結尾>
brand_overlay: <是否套用 U-01、U-02；此專案後續品牌圖卡預設套用>
assets: <公司 Logo、陳董圖片的明確檔案／版本>

1. 讀取選定風格的七頁規格與 Q 清單；核對來源 ID，不能把 O 或 P 說成 E。
2. 先列符合本次媒材的配色、字體、元件、網格、數量上限與禁止事項。
3. 使用者任務覆寫優先於原圖，但只在該任務生效；記錄原規則、覆寫理由與受影響頁。
4. 對來源衝突保留兩條證據。可用已有暫行 P 繼續可逆工作；若必須決定正式規格且無安全的暫行解讀，只詢問該具體問題。
5. 缺少透明度、線寬、動畫時間等不得偽造來源；若製作所需，填入 P 並列入參數清單。
6. 字型缺失、素材缺失、文案過長先明列；不得換掉風格核心或自行認定人物身分。
7. 原圖應用中的健康數字、餐盤、產品資訊是版式範例，不自動複製為真實數據或效能宣稱。
8. 輸出必須含：採用的 R、使用的 U、暫行 P、未決 Q、輸出尺寸、字型／素材版本、逐項驗收結果。
9. 依使用者本次任務執行；沒有製作／發布指示時，不自行生成圖卡或發布。
```

## 6. 執行與驗收模板（P）

| 檢查面向 | 驗收方式 | 失敗處理 |
|---|---|---|
| 來源 | 每項規則能回到 AS-ID／Pxx／原檔名 | 補來源，無來源降為 P |
| 配色 | 色碼角色正確；比例分母已宣告；禁用色未加入 | 更正色碼與角色，不改寫原規格 |
| 字體 | 字族／字重／字級角色對應 P03；中文無缺字 | 揭露替代方案及版面影響 |
| 幾何 | 依 P05 核對欄數、邊距、圓角、數量上限 | 檢查邏輯尺寸與輸出倍率 |
| 內容 | 每卡／每格／每拱的資訊量符合該套規則 | 精簡或拆頁，不任意壓縮字級 |
| 層次 | 文字未被裂紋、圓邊、巨大字或紋樣遮蔽 | 調整圖層與安全區 |
| 品牌 | 適用時核對右上 Logo、封面人物、右下頁碼、完整署名、無玩偶 | 記錄 U 與原規格覆寫位置 |
| 衝突 | 本套 Q 与共用 G-Q 均有適用／不適用／待決狀態 | 不將未決項目寫成通過 |
| 媒材 | 16:9／網站／動態的新增參數均標為 variant 與 P | 禁止拉伸原圖冒充合規改版 |
