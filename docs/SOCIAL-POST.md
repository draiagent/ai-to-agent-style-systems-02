# 讓 Agent 懂你的設計：AS Collection 02，九套可以延續的視覺語言

你是否遇過這種情況？請 AI 做一張圖，效果很好；接著做第二張，字體變了、配色跑了，到了第三張，甚至像另一個品牌。每張單獨看都不錯，放在一起卻不像同一套。

當 AI 開始協助我們製作簡報、圖卡、教材與網頁，真正需要解決的問題，就是：如何讓好的設計持續出現，而不是偶爾出現？這正是 AS Collection 02 設計系統圖卡想處理的事。

這一批收錄九套設計風格，編號從 AS-010 到 AS-018，再以一張總覽封面串起九張風格介紹，形成十張圖卡。每一套都有自己的色彩、字體、元件與版面邏輯，讓人能理解，也讓 Agent 有依據可以執行。

## 設計系統，就像一間餐廳的出餐標準

想像一家餐廳，今天換了廚師，招牌菜的味道就完全不同。即使每位廚師都很有創意，客人仍然難以建立穩定期待。

設計也是如此。色彩像食材，字體像調味，元件像器皿，版面像擺盤，而設計規則就是讓每次出餐維持品質的標準。

規則越清楚，創意越能用在真正重要的地方。Agent 不必每次重新猜測「專業感」或「高級感」是什麼，而能把注意力放在：這段內容該如何說清楚？哪些資訊最重要？讀者應該先看哪裡？這次九套設計，各自提供了不同的答案。

## 01｜澄光琉璃 LUMIFLOW：讓資訊清楚流動

淺色背景、薄荷與青藍色系，搭配通透的玻璃卡片，形成明亮、清晰的閱讀感。右側直式標題建立識別，左側卡片承載內容，金色只作少量點睛。

它適合健康知識、AI 教學與數據解說。核心原則是：一卡一重點。當內容需要一步一步理解，清楚的分層比堆滿資訊更有效。

## 02｜莓紫緞結 KNOT：把重點放在交會處

一條橫帶、一條直帶，在交會處打一個結，就是這套風格的主要語言。莓紫、藕粉與蜜桃粉帶來柔和質感；緞帶承載短句，盒面留給主要內容，玫瑰金則集中在結的位置。

它適合章節導覽、品牌介紹與系列課程。固定資訊有固定位置，讀者便能更快找到方向。

## 03｜焦茶裁字 UMBER：用一個大字留下記憶

同一個色系，從燕麥、奶茶到深褐，建立五階深淺。畫面以一個巨大漢字作為底層主角，裁去一部分，搭配左對齊文字與直角元件，形成鮮明的編輯感。

它適合主題觀點、商業洞察與課程開場。設計前先問自己：如果這一頁只能留下一個字，哪個字最能代表核心？

## 04｜棗拱金珠 ALCOVE：讓內容像展品一樣被看見

棗紅拱形、米白背景與懸垂金珠，構成有秩序的展示空間。一拱只放一個主體，名稱寫在拱下，同一列共用地線。每件內容都有自己的位置，也有足夠的呼吸空間。

它適合產品特色、步驟介紹與案例展示。當你想同時介紹多個項目，先替每個項目保留舞台，讀者才看得見差異。

## 05｜青盒赭扣 CLASP：讓內容走向行動

青色盒子承載資訊，沙色背景降低視覺負擔，赭色則提示最重要的行動。頁首盒與抽屜式資訊形成清楚層次，一個抽屜講一件事，一頁只保留一個主要赭色焦點。

它適合操作指南、服務流程與任務說明。讀完之後，使用者應該知道：下一步要做什麼？

## 06｜紫金對開 FOLIO：用成對結構說清楚關係

左側靛紫，右側鬱金，等寬對開。左邊可以放題名、問題或項目，右邊放內容、回答或示例。細框與襯線字體維持閱讀秩序，讓兩側形成呼應。

它適合問答、觀念與案例、策略與行動。當內容本來就存在配對關係，版面便能直接協助理解。

## 07｜絳青疊瓣 VESICA：讓跨界關係變得可見

絳色與青色圓形互相交疊，交集成為視覺焦點。題名分成兩行，卡片柔和圓潤，透過圓瓣之間的位置與重疊，表達不同領域的連結。

它適合人與 AI 協作、健康生活要素與 OMO 虛實整合。使用時值得多問一句：這些領域交會之後，究竟產生了什麼價值？

## 08｜紫銅經緯 LOOM：先建立秩序，再安排資訊

四欄五列的網格，是這套風格的骨架。素絹、亞麻、紫檀、玄紫與赤銅交錯配置；內容使用整格或合併整格，維持直角、清楚邊界與模組節奏。

它適合分類資訊、課程模組與步驟整理。網格先確定，內容再進場，系列延伸便有共同依據。

## 09｜青釉金繕 CELADON & GILT：用留白與細線串起主題

釉白背景、同族綠色、居中的器形與題名，再用細金線串接畫面。它適合品牌故事、健康教育與跨界理念。文字保持節制，裂紋避開閱讀區，讓細節服務內容。

留白，是替讀者保留理解的時間。

## 從參考圖片，到 Agent 可以使用的規格

這九套風格背後，共有 63 張原始設計圖，分別涵蓋封面、色彩、字體、元件、版面、應用與守則。

整理時，我們將原圖明訂規則、視覺觀察與新增建議分開記錄，並保留衝突與待確認事項。原因很簡單：看起來像規則，不代表原圖真的訂過這條規則。

例如透明度、字級單位或不同媒材的重排方式，若來源沒有說清楚，就應留下問題，不能讓 Agent 自行猜完，再把猜測當成標準。

## 實際使用，只要先交代四件事

1. 選哪套風格？指定 AS 編號與名稱。
2. 要傳達什麼？提供主題、重點與受眾。
3. 要用在哪裡？說明圖卡、簡報、網頁或影片，以及尺寸。
4. 怎樣算完成？列出 Logo、頁碼、署名、文字與版面要求。

例如：「請用 AS-014 青盒赭扣，製作一張 AI 工具操作圖卡，一頁三個步驟，最後保留一個主要行動提示。」這比單純說「幫我做得漂亮一點」，更容易形成可檢查、可修正的成果。

在 AI to Agent 的工作方式裡，設計能力也包含把偏好說清楚、把規則留下來，讓下一次製作有跡可循。

你希望讀者記住什麼？又希望他看完之後做什麼？先回答這兩個問題，再選擇適合的視覺語言，設計才會真正成為溝通的力量。
